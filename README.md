# Chrono Grid: Aether Protocol 🎮

> **2D Turn-Based Grid Puzzle Game** — Game giải đố tư duy chiến thuật đa nền tảng (PC, Mobile, Tablet) chạy trực tiếp trên trình duyệt bằng HTML5 Canvas và JavaScript thuần.

---

## 🌟 Giới Thiệu (About)
Trong **Chrono Grid: Aether Protocol**, bạn điều khiển Robot thám hiểm lượng tử **A.E.T.H.E.R** mắc kẹt trong trạm không gian đang sụp đổ. Nhiệm vụ của bạn là thu thập đủ các **Lõi Năng Lượng (Energy Cores)** và tiến tới **Cổng Dịch Chuyển (Warp Portal)** trước khi cạn kiệt số bước di chuyển (Moves).

## 🚀 Tính Năng Nổi Bật (Features)
- **100% Standalone (Pure HTML5/JS):** Không phụ thuộc bất kỳ thư viện bên ngoài hay hình ảnh, âm thanh ngoài. Chạy mượt mà offline.
- **Tối ưu hóa 60/120 FPS:** Cơ chế lướt mượt mà (Snappy Lerp Animation), xử lý đồ họa vector hiệu năng cao không giật lag.
- **Web Audio API Synthesizer:** Tự tổng hợp âm thanh chân thực (bước chân, đẩy đá, nhặt ngọc, kích hoạt laser, thắng/thua).
- **Hỗ trợ đa thiết bị hoàn hảo (Cross-Platform):**
  - **PC:** Phím Mũi tên / WASD (hỗ trợ cả khi bật gõ tiếng Việt Telex/VNI), Click chuột vào ô xung quanh, Phím số 1, 2, 3, Phím R.
  - **Mobile / Tablet:** Thao tác vuốt màn hình cảm ứng (Swipe), Bàn phím ảo D-Pad trực quan.
- **3 Kỹ Năng Chiến Thuật:**
  - 💥 **Phá Hủy (Break):** Phá vỡ 1 khối đá cản đường phía trước (1 lần/màn).
  - ⚡ **Nhảy Vọt (Jump):** Nhảy vượt qua bẫy gai hoặc vật cản đáp xuống ô an toàn (2 lần/màn).
  - ⏪ **Quay Lui (Undo):** Hoàn tác toàn bộ trạng thái về 1 bước trước (3 lần/màn).
- **Thiết kế màn chơi tăng dần độ khó:** Tích hợp sẵn 3 màn chơi giải đố thông minh.

## 🌐 Chơi Trực Tiếp Trên Web (GitHub Pages)
Sau khi đẩy lên GitHub, bạn có thể bật tính năng **GitHub Pages** để chơi và chia sẻ link cho bạn bè:
1. Vào **Settings** của repository trên GitHub.
2. Chọn mục **Pages** ở thanh bên trái.
3. Ở phần **Branch**, chọn `main` và thư mục `/ (root)`, nhấn **Save**.
4. Đường link game sẽ có dạng: `https://<ten-user>.github.io/<ten-repo>/`
